# Lodesta Awning-Tile Mark

A focused second pass based on a single construction: a clean white `L` inside a Lodesta-green box whose outer bottom edge becomes a three-scallop storefront awning.

These are review assets only. They do not replace the live files in `public/brand/`.

## Controlled Variants

1. `01-classic-serif.svg` — preserves the current compact mark's serif `L` geometry.
2. `02-geometric-sans.svg` — maximizes small-size clarity and product-system alignment.
3. `03-sturdy-slab.svg` — bridges the heritage wordmark and operational product UI.
4. `04-rounded-monoline.svg` — provides a friendlier contemporary treatment.

## Shared Geometry

- Identical `512×512` transparent canvas
- Forest tile: `#24493A`
- Warm-white letter: `#FFFEFA`
- Gently rounded top corners
- Three broad, shallow scallops forming the tile's outer bottom silhouette
- Clear separation between the letter and the awning edge

`scale-test.png` compares all four treatments at 128, 64, 32, and 16 pixels, plus a nearest-neighbor enlargement of each 16px rendering.
