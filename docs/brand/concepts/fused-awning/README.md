# Lodesta Fused-Awning Icon Concepts

Exploratory vector concepts for a compact Lodesta mark derived from the storefront awning in the current wordmark.

These are review assets only. They do not replace the live files in `public/brand/`.

## Directions

1. `01-fused-foot.svg` — the bottom stroke of a geometric `L` becomes three awning scallops.
2. `02-slab-awning.svg` — a slab-serif construction bridges more directly to the current marketing wordmark.
3. `03-storefront-corner.svg` — a geometric `L` sits beneath a distinct three-scallop storefront canopy.
4. `04-open-awning.svg` — the awning works as a freestanding one-color symbol without a letter or app-icon field.

`scale-test.png` shows all four directions at 128, 64, 32, and 16 pixels, plus a nearest-neighbor enlargement of each 16px rendering.

## Fixed Brand Values

- Forest: `#24493A`
- Warm white: `#FFFEFA`
- Paper: `#F6F7F3`
- Three scallops at compact sizes
- One-color glyph geometry with no gradient, shadow, sparkle, or literal browser chrome
