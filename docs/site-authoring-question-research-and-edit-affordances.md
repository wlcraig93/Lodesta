## Bounded implementation

- Document inclusive line replacement, original-file coordinates and insertion before line N using endLine N-1. A current hash prevents stale writes; it does not itself preserve unrelated source.
- Require a nonblank research question before making a provider request and answer only that question, preferring relevant primary authorities for consequential technical advice. Individual third-party review prose stays forbidden.
- Return existing model/search usage through the manager's existing metering field. Completed provider responses with an incomplete report, no retrieved sources, or failed source retention still return their usage-derived estimated cost and a named recoverable tool failure. A completed answer without a search call and consulted sources is unresolved, not retained as researched evidence. No automatic retry or fabricated snapshot is added.
- For author-invoked research, compute a catalog estimate from documented token fields plus the existing per-search estimate, not an undocumented response cost extension. Missing provider usage is explicitly unavailable and triggers the manager's existing telemetry terminal rather than treating unknown model spend as free. The shared estimator and initial Google lookup's existing catalog-estimate behavior are unchanged. Transport exceptions without a reported response do not receive invented charges. OpenAI documents token usage in the [Responses contract](https://developers.openai.com/api/reference/cli/resources/responses/methods/create) and separate model-token and search-call charges in [API pricing](https://developers.openai.com/api/docs/pricing).
- Change the platform descriptor and derived skill identities, not the unchanged system-prompt hash, trusted runtime, source policy or toolchain.
