# Lodesta generated-site fonts

These self-hosted fonts are available to generated customer sites through trusted
platform CSS. Generated source may select the documented family names but may not
load arbitrary fonts.

All files are licensed under the SIL Open Font License 1.1. The corresponding
license text is retained beside each public font binary.

| Family | Source package |
| --- | --- |
| Inter | Existing Lodesta Inter distribution |
| Figtree | Existing Lodesta Figtree distribution |
| Manrope | `@fontsource-variable/manrope@5.3.0` |
| Newsreader | `@fontsource-variable/newsreader@5.3.0` |
| Fraunces | `@fontsource-variable/fraunces@5.3.0` |
| Roboto Condensed | `@fontsource-variable/roboto-condensed@5.3.0` |
